# The post image is integrated into the reusable NewsfeedCard widget using Flutter’s Image.asset widget. Its visibility is controlled by the optional hasImage property: when hasImage is true, the card displays the image inside a clipped, fixed-ratio area using BoxFit.cover; when the property is false or left unset, the image is omitted and no blank space is shown. This lets each newsfeed post use the same card layout, whether or not it includes an image.
